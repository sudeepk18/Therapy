High-Level System Architecture (4-Tier Microservices)

Open Vector SVG

Architecture Highlights for Presentation

  • Client Tier (Port 3000): Built on React 18 + Vite with dual portals: Therapist Dashboard and Client Self-Service Portal.
  • API Gateway (Port 5000): Node.js & Express handling JWT authentication via secure httpOnly cookies and Role-Based Access Control.
  • Subscription Tier Limiting: Dynamic feature flags regulate access to premium AI modules based on therapist SaaS subscription.

AI Microservice & External Integrations

  • AI Inference Service (Port 8001): Python FastAPI running isolated on localhost with X-AI-Service-Key security header.
  • Machine Learning Suite: Scikit-Learn Logistic Regression (No-Show risk), VADER Sentiment Analyzer, and Clinical SOAP NLP.
  • Resilient Fallback: 8-second gateway timeout returns { aiUnavailable: true } without disrupting clinical appointments.

Entity-Relationship (ER) Data Model Schema

Open Vector SVG

Core Data Entities & Multi-Tenancy

  • Therapist (Core Tenant): Owns clients, availability schedules, packages, and credentials. All queries are indexed by therapistId.
  • Client & Intake Records: Encapsulates patient emergency contacts, digital consent with IP audit stamps, and clinical intake medical histories.
  • Session & Notes: Tracks appointment lifecycle, Daily.co WebRTC room tokens, embedded aiRisk, and structured SOAP notes.

Financial & AI Embedded Schema Highlights

  • Flexible Billing: Supports pay-per-session, multi-session bundles (ClientPackage), and Razorpay transaction settlement.
  • Embedded AI Sub-Documents: Session.aiRisk stores no-show probability; SessionNote.aiSentiment tracks VADER valence scores.
  • Clinical Audit Trail: Session notes feature cryptographic SHA-256 digital signatures (isSigned, signatureHash).
